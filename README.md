# Retail Store Sales Analysis
Exploratory Data Analysis (EDA) of retail store sales using Python to understand sales trends, customer behavior, and business insights.

## Project Overview
This project focuses on analyzing retail sales data to identify patterns, understand customer purchasing behavior, and generate meaningful business insights.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Tasks
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Sales Trend Analysis
- Customer Analysis
- Data Visualization
- Business Insights

## Project File
- `Retail_Store_Sales_Analysis.ipynb` – Complete analysis and visualizations.
